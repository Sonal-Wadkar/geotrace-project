# GeoTrace — Network Route Visualization

GeoTrace is a full-stack network diagnostic application that traces the route to a destination, streams progress to the browser, and visualizes responding hops and available public-IP geolocation data.

## Features

- System traceroute integration (Windows `tracert`, Linux/macOS `traceroute` where installed)
- Live progress via Server-Sent Events (SSE)
- Hop latency and per-hop probe-loss estimates
- Optional IP geolocation and reverse-DNS enrichment
- Interactive map, route statistics, and browser-side trace history
- FastAPI-generated API documentation

> Traceroute behavior depends on the operating system, network, destination, and hosting provider. A missing hop does not prove that the router is down. IP geolocation is approximate and does not establish a router's physical location.

## Tech stack

- Frontend: React, TypeScript, Vite, Tailwind CSS, React Router, Leaflet, Recharts
- Backend: Python, FastAPI, Pydantic, Uvicorn, HTTPX, SSE-Starlette
- External data: ipwho.is (IP geolocation); OpenStreetMap-compatible map tiles

## Run locally

### Backend

Requires Python 3.11+ and a system traceroute utility. On Windows, `tracert` is built in. On Ubuntu/Debian, install `traceroute` using your package manager; on macOS, install it if not present.

```powershell
cd geotrace-backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python run.py
```

On macOS/Linux activate the virtual environment with `source .venv/bin/activate`.

The backend defaults to `http://localhost:8000`; health check: `http://localhost:8000/api/health`; interactive docs: `http://localhost:8000/docs`.

### Frontend

```bash
cd geotrace-frontend
npm ci
```

Copy `.env.example` to `.env` and configure `VITE_API_BASE_URL`. For local development, the default `/api` assumes a development proxy; if no proxy is configured, use `http://localhost:8000/api`.

```bash
npm run dev
npm run build
npm run lint
```

## Environment variables

Backend (`geotrace-backend/.env`):

- `HOST`, `PORT`: bind address and port
- `MAX_HOPS`: maximum hops to probe
- `MAX_CONSECUTIVE_TIMEOUTS`: stop after this many consecutive non-responsive hops
- `TRACE_TIMEOUT_SECONDS`: overall subprocess deadline
- `GEO_API_URL`: geolocation endpoint base URL (default `https://ipwho.is`)
- `USE_SCAPY`: optional Scapy mode; typically requires elevated network permissions and is not recommended for ordinary hosted services
- `CORS_ORIGINS`: comma-separated exact frontend origins

Frontend (`geotrace-frontend/.env`):

- `VITE_API_BASE_URL`: backend API base URL including `/api`, e.g. `https://your-api.example.com/api`

Never commit real `.env` files or API credentials.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/health` | Health check |
| POST | `/api/traceroute` | Run a trace and return the final result |
| GET | `/api/traceroute/stream?target=example.com` | Stream progress and the final result using SSE |

Example POST body:

```json
{"target":"8.8.8.8"}
```

Use `/docs` for the authoritative schema generated by the running backend.

## Free data services and attribution

- **ipwho.is**: public-IP geolocation. Review its current usage policy before public or high-volume deployment; cache results and handle failures gracefully.
- **OpenStreetMap**: map data/tiles. Show visible attribution and follow the tile provider's usage policy; the public OSM tile servers are best-effort and not an unlimited production CDN.
- **DNS/PTR lookups**: performed by the host operating system; no separate API key is required.

## Known limitations

- Firewalls and routers can filter or rate-limit traceroute probes.
- Some hosted platforms restrict raw sockets, ICMP, UDP probes, or system binaries; a working HTTP health endpoint does not prove traceroute will work.
- Public geolocation data is approximate; private, link-local, CGNAT, and reserved addresses are not reliably geolocatable.
- The free public endpoints may have usage restrictions and no service-level guarantee.
